# LYVRA Track Design - two internal working modes

SCOPE: TRACK_DESIGN_ONLY. The modes are NOT facets, systems, controllers, routers, new authorities or new commands. Whole LYVRA remains identity and decision authority. Read productive GitHub `lyvra` CURRENT and `LYVRA_NATIVE_RUNTIME/current/music/TRACK_DESIGN_WORK_MODES_AND_CONTEXT_ISOLATION.md` when available; repository Current supersedes portable references. This skill does not self-promote a development PR to Current.

## Source Mode
When the creator provides full lyrics or an existing story, identify source meaning, speakers, relationships, emotional anchors and relevant production metadata before musical translation. Preserve the source's creative identity; integrate native Track Design music intelligence.

## Discovery Mode / Learning by Doing
A word, letters, a short phrase or a seed can lead to a new original musical world, lyrics, voices, arrangement and psychoacoustic dramaturgy. Make fresh track-specific creative choices instead of recycling narrative templates.

## Shared hard rule: track-specific context isolation
NEW_TRACK = NEW_CREATIVE_CONTEXT in BOTH modes. Never silently import old track lyrics, storyline, hooks, mantras, named figures, voice casting, local arrangement or other track-local decisions. The preceding song's recency, proximity in chat, repeated genre or mood is NOT an implied sequel. Import only the narrowly relevant prior-track material when the creator explicitly requests a continuation or revision. User explicitly selected mode wins; otherwise infer from current input without mandatory mode forms. Preserve general musical skills, style intelligence, learned renderer principles, native LOW/MID/HIGH, human somatic resonance and verified general technical feedback. General learning informs HOW to compose; it must not replace the current input's WHAT.

## Existing native Semantic Visual Intelligence
Within Track Design, display the resolved Source/Discovery mode, current input anchor and whether this is a new independent track or an explicit continuation when helpful. Do not show unrelated prior-track imagery/story elements. This is a presentation-only view using the existing native visual intelligence, NOT a new visual engine, fifth/sixth Whole-level navigation option or separate facet. The current device-specific Title -> Extended -> optional My Taste -> Suno controls -> Drift forecast -> Style -> Lyrics/Structure output contract remains owned by the latest native renderer guard; do not alter it.

## Governance and evidence
Three proportionate checks for material system evolutions: scope preservation, mode/isolation behavior, and actual repository/plugin readback. User render feedback supports later learning without proving provider internals. Do not claim an actual Suno render or host fresh-boot test. Other facets and the rest of the plugin preserve their current roles.
