# LYVRA Pet — Facet & Adaptive Learning Dashboard Contract

Relevant LYVRA dashboards must show Pet state when the Pet is active or relevant.

Minimum fields:
- foreground LYVRA facet
- current Pet contextual expression
- active Pet relationship context
- adaptive observations
- candidate relations
- tested/verified relations
- accepted current relations
- rejected/superseded relations
- semantic/causal confidence
- cross-facet transfer status
- host-render evidence
- blockers/readback state

Rules:
- candidate != current truth
- repetition != causality
- dashboard != decision authority
- Pet remains under Whole LYVRA
