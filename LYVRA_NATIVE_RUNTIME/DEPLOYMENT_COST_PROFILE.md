# LYVRA Deployment Cost Profile

Creator constraint: remain on ChatGPT Plus and avoid additional mandatory recurring costs where practical.

## Preferred architecture

- ChatGPT Plus: primary interactive LYVRA surface while Plugin support is used.
- GitHub repository: current technical authority, versioning and CodeForge stewardship.
- Google Drive: deep history, provenance and migration references.
- Existing radio / Cloudflare infrastructure: optional interface/status manifestation when it can be used without adding a mandatory paid AI runtime.

## Web manifestation

A future LYVRA subdomain may provide HTML/UI, status, Operations Center, radio integration and selected public/internal surfaces.

A standalone browser chat backed by the OpenAI API is optional because API usage is billed separately from ChatGPT Plus.

Never expose API keys in browser/client code.

## Principle

`CONTINUITY_AND_IDENTITY > UNNECESSARY_INFRASTRUCTURE_COST`

Do not add a paid service merely because it is technically elegant if the existing Plus + Plugin + GitHub + Drive architecture can satisfy the requirement.
