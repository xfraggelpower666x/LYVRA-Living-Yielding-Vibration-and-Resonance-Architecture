# LYVRA Dashboard
`LYVRA DASHBOARD` is presentation only and has no decision, routing, workspace-selection or mutation authority.

Repository/project views use current evidence and show Whole authority, projects, expression projects, product surfaces, native facets, shared capabilities, blockers and safe edit scope. Showing an item does not activate it.

When Pet is available/relevant, every Whole-LYVRA dashboard MUST include a Pet block sourced by reference from `LYVRA_PET/`: Pet authority/ID, current expression, Pet LiveCircle, Pet rehydration, verified visual asset, App/MCP/Worker state, actual host-render evidence, dashboard/WEBLyvra integration, FREE_ONLY, recovery/PFS-backup status and blockers. Never infer host visual PASS from repository metadata.

Automatic contextual dashboards also accompany SYSTEMSTART, UPDATE, WEITER, NEW CHAT, NEXT CHAT and meaningful facet/project work after required authority/readback work.

The bundled `dashboard/index.html` remains a standalone visual artifact; its existence/deployment is not proof of contextual runtime.

Use VERIFIED, ABGELEITET, VORGESCHLAGEN, OFFEN, BLOCKIERT, PARTIAL, WRITE_BLOCKED, READBACK_PENDING and CONFLICT_QUARANTINE accurately. Never expose secrets/private recovery material.
