# LYVRA UPDATE governance + dashboard
1. Rehydrate current LYVRA authority and resolve the current chat's primary workspace before mutation.
2. UPDATE is ADDITIVE_CURRENT_REFRESH. Preserve active workspace and active work unless explicitly changed.
3. Reconcile newer valid Whole-LYVRA evolution plus causally relevant workspace evolution.
4. Check relevant peer handoff/outbox carriers for improvement proposals. Proposal reads are read-only. PROPOSAL_FOUND_NE_ADOPTED.
5. NOTICE_RECEIVED_NE_STATE_UNDERSTOOD. Before a foreign notice may materially update LYVRA understanding, directly read the target system's current native authority and exact relevant current carriers. NOTICE_ONLY_CARD_UPDATE=FORBIDDEN.
6. Coupled plugin-backup execution requires STABLE_SET_CONVERGENCE across LYVRA Account, LYVRA Native and CLIC release/fingerprint/approval state. Fingerprint/release/approval supersession breaks the candidate set; governance-only HEAD movement does not when the same fingerprint revalidates. ONE_LEG_READY_NE_COUPLED_STABLE_SET.
7. When plugin binaries cannot be directly mirrored/read-hashed live, use HYBRID_RELEASE_SNAPSHOT binding: path + SHA-256 + bytes + exact plugin_id/version/release_id + provenance. This is not direct live hash readback or repo byte parity. Backup executor must hash extracted bound binaries.
8. After meaningful LYVRA-native development, prepare an informational peer notice when causally relevant. NOTICE_NE_TRIGGER; NOTICE_NE_AUTHORITY_TRANSFER; NOTICE_NE_FOREIGN_AUTOACTIVATION; NOTICE_NE_AUTOADOPTION.
9. Verify target, permissions, fresh HEAD, expected SHAs and recovery point before writes.
10. Use optimistic concurrency and CONFLICT_QUARANTINE on unexpected movement.
11. Perform smallest correct mutation and direct readback.
12. Every semantic runtime evolution runs plugin impact checks on both LYVRA plugin surfaces; affected surfaces evolve in the same UPDATE.
13. Backup approvals bind to reproducible runtime/plugin state fingerprint, not arbitrary later HEAD movement.
14. Close in order: body -> readback -> plugin impact/release/readback -> fingerprints/coverage/manifest -> CURRENT pointer last -> readback only.
15. Preserve workspace/lineage continuity; no global last-workspace-wins pointer.

Hard boundary: REPO_CURRENT_WINS=TRUE; GLOBAL_ACTIVE_WORKSPACE=FORBIDDEN; DRIVE_NORMAL_UPDATE_DEPENDENCY=FORBIDDEN; SILENT_PLUGIN_DRIFT=FORBIDDEN; FOREIGN_PROPOSAL_AUTOADOPTION=FORBIDDEN.
