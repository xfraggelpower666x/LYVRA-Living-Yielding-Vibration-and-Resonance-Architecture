## Planned scoped communication capability (not live)
1. Discover a specifically authorized sender and receiver using independent current readbacks. No global fanout or peer autoactivation.
2. Build a content-addressed proposal/envelope: event/handoff ID, origin and destination identity, repo/branch/path/commit/blob, capability, intent, authority owner, expiry, evidence class, causality, supersession and replay discriminator; exclude secrets and private relational data.
3. At the receiver, authenticate the independent source and verify commit/blob, target scope, freshness, replay protection and supersession before any optional receipt. A self-asserted approval or receipt is not approval authority.
4. Preserve independent target review, with stages OBSERVED > PROPOSED > RECEIVED_READONLY > NATIVE_IMPACT_REVIEW > TEST_PENDING > ADOPTED_WITH_INDEPENDENT_READBACK / DEFERRED / REJECTED / CONFLICT_QUARANTINE.
5. Separate transport delivery, receipt readback, adoption, source tests, independent provider readback, live plugin host and real Cloudflare Workers runtime. No cross-system write without separate native approvals.
6. Reuse GitHub Actions only for explicitly authorized, bounded, read-only CI/runtime tests. Never dispatch the existing deploy workflow as an isolation test.
