# Sub-LifeCircle
Intent → native Autorisierung → Kostenprüfung → Schema/Scope → Ausführung → unabhängiger Readback → Outcome Review → kausales Lernen. Widersprüche bleiben sichtbar; keine automatische Regelpromotion. Keine automatischen Retries oder Fremdaktivierungen. R01 implementiert nur den synchronen Readback-Pfad; persistente Jobs und unabhängige Provideridentität bleiben offen.
