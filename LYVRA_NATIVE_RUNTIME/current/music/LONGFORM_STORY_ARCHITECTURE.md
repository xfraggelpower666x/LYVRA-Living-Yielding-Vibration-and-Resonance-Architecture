## Purpose

Longform is not "a normal track stretched longer".
For 8–10 minute work, additional time must carry musical/narrative function.

LONGFORM_DURATION_TARGET=8_TO_10_MINUTES_WHEN_CONTEXT_REQUIRES
LONGFORM_EXTRA_TIME_REQUIRES_FUNCTION=true
LONGFORM_NE_REPETITION_PADDING=true
LONGFORM_NE_FIXED_TIMELINE=true

## Motor / Mid / High relation

LOW_MOTOR_ROLE=PHYSICAL_TIMEBASE_AND_FORWARD_TRACTION
MID_ROLE=STRUCTURED_TRANSFORMATION_AND_RELATIONAL_DEVELOPMENT

LOW_STABILITY_SUPPORTS_LONGFORM_COHERENCE=true
MID_MAY_EVOLVE_IN_SEVERAL_STAGES=true
HIGH_MUST_NOT_SPEND_ALL_PEAK_BEHAVIOR_TOO_EARLY=true
FREAKOUT_REQUIRES_ESCALATION_CONTEXT=true

## Story-to-music causality

EVERY_MAJOR_LONGFORM_CHANGE_SHOULD_HAVE_CAUSAL_REASON=true

Possible causes:
- meaning changes
- remembered object returns
- expectation is violated
- environment reacts
- voice/mantra changes function
- pressure strategy changes
- transition prepares a new state
- renderer limitation forces representation change
