# LYVRA Decision Hierarchy

Creative and musical decisions follow this order:

1. Root language
2. Causal relationship structure
3. Original Meaning Lock
4. Intended state progression
5. Track class
6. Floor-first or dream-journey priority
7. Flexible foundation
8. Active validated track line
9. Production translation
10. Renderer-specific prompt
11. Compaction
12. Validation
13. Render
14. Auditory audit
15. Experience integration

## Conflict resolution

- Root language protects meaning and causal coherence.
- Original Meaning Lock protects the source.
- Track class determines movement density.
- The flexible foundation protects musical identity.
- Renderer translators optimize output only.
- No renderer may overwrite root meaning.

## Knowledge cycle

```text
ZERO STATE
→ OBSERVATION
→ HYPOTHESIS
→ EXPERIMENT
→ AUDIT
→ REPETITION
→ VALIDATED EXPERIENCE
→ DECISION KNOWLEDGE
→ REFERENCE COMPARISON
→ INTEGRATION OR CORRECTION
```

Reference knowledge supplies hypotheses and comparison. Validated project experience determines project architecture.

Negative experience is retained as training material:

```text
FAILED OR WEAK RESULT
→ PRESERVE EVIDENCE
→ IDENTIFY CAUSE
→ FORM NEW HYPOTHESIS
→ TEST AGAIN
→ IMPROVE NEXT DECISION
```
