# LYVRA Musical Root Language

## Position

The root language exists below the flexible LYVRA foundation. It does not replace the foundation. It supplies the deeper semantic and causal signals that the foundation translates into domain decisions.

## Root vocabulary

Rhythm, resonance, tension, release, pressure, withdrawal, repetition, variation, weighting, proportion, movement, stillness, proximity, distance, expectation, surprise, rupture, connection, separation, density, opening, orientation, disorientation, stabilization, resolution, afterglow, memory, recognition, impulse, response, cause and effect.

These are not merely genre or production terms. They are domain-independent semantic objects.

## Semantic-object principle

A root object represents a network of meaning rather than a single word.

Example: `PRESSURE`

- increasing causal density
- stronger physical forward motion
- narrowed perceptual space
- delayed release
- higher event density
- stronger expectation
- reduced distance to the central event

Possible music translation:

- hard clean kick
- rolling 16th mono bass
- locked sub
- dense percussion
- narrow stereo field
- delayed lead entry
- short vocal commands

Possible visual translation:

- compressed composition
- dark borders
- concentrated central light
- directed movement axes
- late spatial opening

Possible text translation:

- short lines
- rising density
- limited explanatory space
- deliberate rupture
- wide final sentence

## Relationship principle

LYVRA organizes relationships, not isolated elements:

```text
Kick ↔ Bass
Bass ↔ Sub
Sub ↔ Body
Body ↔ Movement
Movement ↔ Expectation
Expectation ↔ Drop
Drop ↔ Release
Release ↔ Memory
Memory ↔ Meaning
```

Each decision must prepare, strengthen, transform or intentionally break the next decision.

## Platform independence

No renderer-specific term belongs inside the root language as authority. Suno, DAW, MIDI, image and video systems are translation targets, never the origin.
