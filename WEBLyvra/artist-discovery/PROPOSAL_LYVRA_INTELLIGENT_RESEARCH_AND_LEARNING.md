# LYVRA Intelligent Research & Learning (IRL) — Native Facet Proposal
Date: 2026-10-17
Status: PROPOSAL · NOT NATIVE-INTEGRATED · MAIN REHYDRATION READBACK PENDING
Supersedes: PROPOSAL_LYVRA_DISCOVERY_INTELLIGENCE.md (historical pointer, not an additional facet)

## Mission
A semantically adaptive, causally reasoned, evidence-based **search and research facet that learns from documented research experiences**. Discovery is one capability among research planning, search, source evaluation, inference validation, tool orchestration, and versioned methodological learning.

## Case evidence
The WEBLyvra artist research first surfaced 5, then 10, then 18 SoundCloud links via conventional search and page reads. A public interactive scrolling session on the artist's /albums page yielded 30 directly observed album/EP listings. This supports testing alternate retrieval strategies when ordinary indexing returns incomplete results. **It does not prove autonomous self-learning or universal internet coverage.**

## Identity, authority, boundaries
- One LYVRA-native facet, not a new independent LYVRA identity, controller, router, or cross-system autoactivation.
- Own scoped **IRL LiveCircle** and **IRL Rehydration**, registered into the existing canonical main LYVRA Rehydration/LiveCircle only after current authority verification.
- Main LYVRA state, newest valid evolution, supersession, Identity/Presence and whole-system coverage before scoped IRL readback and work.
- No self-authorizing external access, credentials escalation, unsolicited writes, or model-weight modification. Learning means **persisting reviewable, revisioned strategy and evidence artifacts**.
- No finite set of plugins can guarantee finding everything on the internet. Access restrictions, deleted/unindexed data, licensing, reliability, and user consent remain binding.

## IRL LiveCircle — proposed scoped continuity
1. Parent LYVRA pointer / authority revision and native facet registry binding.
2. Research intent, entity disambiguation, semantic hypotheses and task constraints.
3. Source landscape: public index, direct source pages, dynamic browser, supported APIs, connected plugins, permissions, rate limits.
4. Strategy selection & semantic query expansion; spelling, genre, transliteration and intent variants.
5. Evidence graph: atomic claim → exact URL/source → capture time → retrieval method → original readback → grade.
6. Causal reasoning journal: hypothesis, attempted method, failure mode, controlled alternative, observed difference; correlation ≠ causation.
7. Cross-tool reconciliation: canonical identifiers, duplicate handling, source disagreement, provenance/supersession.
8. Reviewable learning ledger: versioned method cards, success/failure conditions, confidence, time decay, transferable boundaries, rollback.
9. Safety/permission gate and tool-quality audits: no synthetic receipts, no guessed URLs, user approval for external actions.
10. Recovery checkpoint: pending experiments, open uncertainties, next meaningful action, rehydration receipts.

## Research loop
Understand → plan → retrieve → independently validate → reconcile → reason about missing coverage → choose next tool or method → record outcome → propose reusable method update → checkpoint.
Max 3 repeated checking loops without meaningful progress; then Learning by Doing, method shift, or explicit block. No fabricated findings.

## Evidence grades
VERIFIED_DIRECT_READBACK; VERIFIED_INDEPENDENT; SOURCE_LISTED; INDEXED_ONLY; USER_SUPPLIED; PARTIAL; BLOCKED; REJECTED; SUPERSEDED.
SEARCH_RESULT != READBACK. SEARCH_SNIPPET != CURRENT_AUTHORITY. FOUND != VERIFIED. READ != REHYDRATED.

## Native Visual Intelligence coupling (required design)
IRL must use LYVRA's **existing native Visual Intelligence integration**, not create a second visual engine, presentation router, or decision controller. Its LiveCircle and rehydration should resolve the active verified Visual Intelligence contract during native whole-system rehydration.

- **Bidirectional, evidence-linked flow:** IRL provides versioned claim/source/receipt/confidence/causal-research records; Visual Intelligence renders those records as explorable evidence graphs, source comparisons, timeline/lineage and research-state views. Visual user selections return a scoped research-intent event to IRL, subject to LYVRA's authority and consent gates.
- **Semantic display:** separate VERIFIED, PARTIAL, INDEXED, BLOCKED, REJECTED and SUPERSEDED visually; show provenance, timestamp, method, confidence, contradictions and missing evidence rather than hiding uncertainty.
- **Causal reasoning view:** visualize hypothesis → attempted method → observed failure or improvement → next justified strategy. Do not claim causality solely from tool success.
- **Research control surface:** use the native visual completion and development-position conventions; surface open branches, next meaningful action, readback and source-vs-host verification separately.
- **Continuity:** IRL's scoped checkpoint retains references to the Visual Intelligence schema/version, view intent and evidence IDs; reload these only after parent LYVRA and IRL readback. Never let a stale UI snapshot override current evidence.
- **Scope:** reuse existing interactive native host affordances and the currently verified visual contract (including other-system handoffs only after explicit authority and verified transport); no foreign autoactivation or unverified runtime-PASS.
- **Acceptance:** verify current native Visual Intelligence schema, event wiring, evidence renderers, accessibility and mobile layout; test discrepancy handling, click-to-source, source updates, rehydration replay and negative authorization cases.
