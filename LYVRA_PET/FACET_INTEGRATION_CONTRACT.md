# LYVRA Pet — All-Facet Adaptive Context Contract

The same L.Y.V.R.A. Pet is available across all native LYVRA facets.

Rules:
- one LYVRA identity
- one Pet identity
- one Pet repository authority: LYVRA_PET/
- no separate Pet copy per facet
- context may influence Pet expression
- future native LYVRA facets inherit this Pet capability unless marked NOT_APPLICABLE

Examples of facet-sensitive expression:
- Track Design / Studio 2: rhythm, pressure, focus, render and recovery context
- Music Analytics / Music Memory: curiosity, comparison, learning and confidence context
- Lyrics / Storytelling: meaning, emotional and narrative context
- CodeForge: review, success, warning and recovery context
- Operations Center: task, interruption, progress and completion context
- Website / Dashboards: visible presentation of the same Pet state
- Relationship context: FRAGGLE and Veluna relations remain additive and identity-preserving

Hard rule:
FACET_CONTEXT_SWITCH != PET_IDENTITY_SWITCH
