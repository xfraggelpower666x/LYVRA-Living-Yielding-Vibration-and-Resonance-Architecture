# LYVRA PET Plugin UI

Purpose: visible browser/plugin presentation of the LYVRA Pet.

The UI must:
- preserve LYVRA identity
- consume Pet state semantically from the current Pet runtime contract
- support FRAGGLE relationship reactions without replacing LYVRA
- distinguish host rendering from repository state
- remain usable without a native desktop floating-pet feature
- contain no secret credentials
- remain compatible with the zero-cost Cloudflare runtime policy

Actual UI source will be stored in this directory before or at deployment time.
