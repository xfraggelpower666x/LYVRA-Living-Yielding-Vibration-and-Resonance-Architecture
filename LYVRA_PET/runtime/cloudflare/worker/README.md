# LYVRA Pet Worker

Free-only Cloudflare Worker source for the LYVRA Pet MCP/App bridge.

Planned endpoints:
- `/health`
- `/pet`
- `/mcp`

No paid storage, Durable Objects, Workflows or third-party APIs.

The MCP opener tool will link to `ui://lyvra/pet-v1.html` and advertise browser app entrypoints.

The UI must not fabricate a replacement sprite while the verified binary atlas awaits repository binary transport.
